# How to Launch the Certificate System

To view the frontend and start generating certificates, follow these steps:

1.  **Open a Terminal** (Command Prompt or PowerShell).
2.  **Navigate to the frontend folder**:
    ```bash
    cd "c:\Users\hp\OneDrive\Desktop\AIML Role assignments\Assignment 2 Certificate Generator\frontend"
    ```
3.  **Install Dependencies** (only needed once):
    ```bash
    npm install
    ```
4.  **Start the Server**:
    ```bash
    npm run dev
    ```
5.  **View the App**:
    - Look for a link like `http://localhost:5173` in the terminal.
    - Click it or copy-paste it into your browser.

> I have already started this process for you in the background! Keep an eye on the terminal output.
