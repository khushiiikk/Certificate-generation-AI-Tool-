> **Propagate high-fidelity aviation credentials with an intelligent, recursive certification protocol.**

Welcome to the **IFOA India Certificate Generator**, a professional-grade AI-powered tool designed to automate the issuance, management, and verification of training certificates. Built with a premium "Glassmorphism" aesthetic and futuristic animations, this tool ensures that your organization's compliance registry is both beautiful and functional.

---

## 🚀 Core Protocols & Features

### 💎 1. Neural Design Library
Choose from five localized, high-definition certificate templates tailored for different certification tiers:
- **GOLD EDITION**: The timeless classic for executive credentials.
- **ONYX EDITION**: Sleek, modern, and stealthy.
- **BLUE EDITION**: Focused on corporate trust and technical modules.
- **GREEN EDITION**: The aviation standard for safety compliance.
- **RED EDITION**: High-visibility for critical or urgent ratings.

### 📊 2. Registry Database (L3 Node)
A robust management system to store and track every participant credential:
- **Participant Data**: Name, Company, Department, and Training History.
- **Smart Tracking**: Real-time filtering and search through the Global Compliance Registry.
- **Action Buffer**: Instant "Generate Certificate / Download PDF" triggers for every record.

### ⚙️ 3. Autonomous Generation Logic
- **Dynamic Validity**: Automatically calculates a strict **1-year (12 months)** expiration cycle from the training date.
- **EASA Module Mapping**: Specifically for **Flight Dispatcher Recurrent** training, users can multi-select technical modules (Air Law, Navigation, Meteorology, etc.) to be injected into the certificate body.
- **Dual Signature Matrix**: Integrated management for **COO (Kenneth Kronborg)** and **CEO (Vincent Incammicia)** signatures (supports text-rendering or high-res PNG uploads).

### 🔍 4. Verification & Export
- **QR Neural Link**: Every certificate features a unique QR code for instant digital verification via the IFOA portal.
- **Multi-Format Export**: High-fidelity PDF generation and rasterized JPG exports for print or digital distribution.
- **Verification Nodes**: Interactive QR scanner positioning for professional footer layout.

### 🤖 5. Copilot Assistant
A built-in AI assistant (**"How may I help you?"**) to guide users through the certification flow, provide support, and manage system settings.

- **Animations**: Framer Motion

- **Export Engine**: html-to-image & jsPDF
- **QR Generation**: qrcode.react
- **Styling**: Tailwind CSS v3



